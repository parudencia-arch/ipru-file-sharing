How DropLink Works
1
🔗
Connect via Peer ID
Share your unique Peer ID with the recipient. They paste it in to establish a direct browser-to-browser connection via WebRTC.
2
📤
Drop Your Files
Drag and drop files up to 100MB each. Files are chunked and streamed directly to the other browser — no server in between.
3
⚡
Instant & Private
Transfers happen at full network speed. For text, generate a shareable link — content is encoded in the URL itself, zero storage.
Built with WebRTC · No servers · No tracking · 100% client-side
DropLink uses PeerJS for signaling and WebRTC for direct P2P transfers. Text links use LZ-string URL compression. No data is ever stored on any server.
